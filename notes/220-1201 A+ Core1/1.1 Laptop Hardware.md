# 1.1 Laptop Hardware

## Laptop Hardware Overview
- Engineered to precise specifications → Repairs can be challenging.
- Some laptops easier to fix than others → Requires understanding manufacturer details.

## Laptop Batteries
- Power source when unplugged.
- Easily replaced or may require teardown.
- Lithium-Ion (Li-ion) and Lithium-Ion Polymer (LiPo).
- No memory effect; charging does not reduce capacity.

## Laptop Keyboard
- Most-used component.
- Replacement: few screws and ribbon cable.
- External USB keyboard as backup.

## Laptop Keys
- May require removal/replacement.
- Follow manufacturer instructions.

## Laptop Memory
- SO-DIMM (Small Outline Dual In-line Memory Module).
- Common in laptops/mobile devices.
- Some soldered to system board → No upgrade possible.

## Laptop Storage
- Magnetic Disk: Spinning platters, 2.5" form factor.
- SSD: No moving parts, fast access.
- M.2: Smaller form factor, easy to install.

### Replacing Laptop Storage
- Internal replacement: open back cover.
- Modular design: two screws.
- M.2 drives: one screw.

### Migrating from HDD to SSD
- Upgrade benefits: faster performance.
- Steps: Install OS, move documents, install apps.
- Options: Image/clone HDD, imaging software.

## Wireless & Bluetooth
- 802.11 Wireless: LAN connectivity.
- Bluetooth: PAN (Personal Area Network).

## Biometrics
- Fingerprint or face recognition.
- Requires OS configuration.

## Near-Field Communication (NFC)
- Short-distance networking (≤4 cm).
- Data transfer or authentication.

## Wi-Fi Antennas
- Multiple antennas (main, aux).
- Bluetooth integrated.

## Microphone
- Built-in for video calls.
- Analog or USB external options.
